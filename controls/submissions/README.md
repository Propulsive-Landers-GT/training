# Submissions

Your exercise work goes here, in a folder named after your GitHub handle:

```
controls/submissions/<your-github-handle>/
  ex1_hover_pid.py        copied from ../../exercises/ and filled in
  ex2_lqr_tvc.py          (if you did it)
  ex3_mpc_receding_horizon.py
  RESULTS.md              the metric tables the scripts print, plus a few sentences on what surprised you
  *.png                   the plots you want reviewed (keep them small; the scripts write at 120 dpi)
```

Then open a pull request titled `Controls tutorial: <your name>` and ask in #gnc for a review.
Rough is fine. Half-done with a question in the PR is also fine.

The exact steps are in [the exercises README](../exercises/README.md).
